# Color Palette

The palette used across the mkdocs site (`mkdocs.yml`, `docs/stylesheets/extra.css`), the
SVG assets (`assets/`), and the benchmark figures (`docs/figures/`).

## Backgrounds

| Swatch | Hex | Role |
|---|---|---|
| ⬛ | `#0a0a0f` | Primary fg / header / tabs background |
| ⬛ | `#050508` | Primary fg, dark variant |
| ⬛ | `#111118` | Default page background |
| 🟪 | `#1a1a2e` | Primary fg, light variant |
| ⬛ | `#1e293b` | Figure dark element |
| ⬜ | `#64748b` | Figure muted/gray |

## Accent

| Swatch | Hex | Role |
|---|---|---|
| 🟧 | `#f77f00` | Primary accent (Material accent color, banner glow trigger, figure highlight) |
| 🟧 | `#d96800` | Accent, darker |
| 🟦 | `#0ea5e9` | Link hover / figure primary series |
| 🩵 | `#38bdf8` | Inline link default |
| 🔵 | `#0890cc` | Icon accent |
| 🟣 | `#7c3aed` | Nav hover / banner glow (`rgba(124,58,237,0.2)`) |
| 🟣 | `#9b59ff` | Active nav item |
| 🟪 | `#9b80dd` | Logo accent |
| 🩷 | `#e040c0` | Icon/figure magenta accent |
| 🟪 | `#c02898` | Icon magenta, darker |
| 🩵 | `#a9ddf7` | Figure light-blue fill |
| 🟧 | `#fcd2a3` | Figure light-orange fill |
| ⬜ | `#e8e0d0` | Logo off-white/cream |
| ⬜ | `#fbfbfd` | Figure near-white |

## Summary

Near-black slate background, with orange (`#f77f00`) as the primary accent, cyan/blue
(`#0ea5e9` / `#38bdf8`) for links, and purple (`#7c3aed` / `#9b59ff`) for navigation
state, plus a magenta (`#e040c0`) used sparingly in the icon/logo and figures.
